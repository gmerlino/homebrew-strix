# Gmerlino Strix

## How do I install these formulae?

`brew install gmerlino/strix/<formula>`

Or `brew tap gmerlino/strix` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "gmerlino/strix"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
